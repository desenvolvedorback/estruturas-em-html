1. Introdução
    1. O que é HTML?
      1. É a linguagem de marcação padrão usada para criar, definir e estruturar todo o conteúdo e os elementos de uma página web.
    2. O que é XHTML?
      1. É uma reformulação do HTML 4.01, que combina a flexibilidade do HTML com a rigorosidade do XML.
    3. O que é CSS?
      1. É uma linguagem de estilo usada para controlar a apresentação de elementos HTML em uma página web.
    4. O que é W3C?
      1. É a organização responsável por desenvolver padrões para a web, como HTML, XHTML e CSS.
